# trame

Monorepo pnpm workspaces (apps/web, apps/api, packages/core, packages/engine, packages/ooxml).

- `pnpm install` — installe les dépendances de tous les packages.
- `pnpm dev` — lance les scripts `dev` de chaque app en parallèle.
- `pnpm test` — lance la suite de tests (Vitest) sur tout le monorepo.
- `pnpm lint` — lance ESLint sur tout le monorepo.
